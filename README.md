**Nunes-Sports**
**Status: Completo ✅**

O NunesSport é uma aplicação desenvolvida em HTML, fruto do desafio da Everymind. Abaixo estão os principais aspectos e requisitos atendidos:

**Desafios e Soluções:**
- **Modelo de Entrega:** Estabelecido com sucesso ✅
- **Ferramentas de Mercado:** Utilizadas as mais atuais ✅
- **Sistema de Produtos:** Implementado para exibir, criar, editar e excluir produtos ✅
- **Base de Dados:** Inclui uma tabela com os seguintes campos: nome, código, descrição e preço dos produtos ✅
- **Página Web:** Criada para operações CRUD (criar, ler, atualizar e deletar) de produtos ✅
- **Funcionalidade do Usuário:** Permite ao usuário criar, editar, excluir e visualizar produtos salvos na tabela ✅
- **Sincronização:** Todas as ações na página refletem no banco de dados ✅

**Objetivos Principais:**
- **Criatividade**
- **Capacidade de Resolução de Problemas**
- **Qualidade do Código**
- **Organização**
- **Boas Práticas**
- **Código Limpo (Clean Code)**

**Detalhes do Site:**
Para facilitar a edição da página, foi integrada a biblioteca **Bootstrap** para aprimorar a estilização. Os dados são armazenados no **LocalStorage**, que funciona como o banco de dados da aplicação.

**Tela de Cadastro:**
- **Email:** Deve ser preenchido e Conter "@"
- **Senha:** Deve ter no minhno 8 caracteres e ser confirmada corretamente
- ![image](https://github.com/user-attachments/assets/a8fc3476-ff2c-44f9-9a1d-625a28f4e1e1)


**Tela de Login:**
- **Usuário:** Use o email e senha cadastrados na tela de registro
- **Cadastro:** Se ainda não tiver uma conta, clique em "Criar Conta" para ser direcionado à página de Cadastro
- ![image](https://github.com/user-attachments/assets/5dd8466e-d9ec-4c57-96d8-2a87f8a7efed)


**Página Inicial:**
- **Cadastro de Produtos:** o Botao Cadastrar permite adicionar novos produtos
- **Logout:** Opção para encerrar a sessão
- **Tabela de Produtos:** Cada linha possui dois Botões 
  - **Editar :** Permite modificar os dados do produto
  - **Excluir :** Remove o produto da tabela e do LocalStorage
